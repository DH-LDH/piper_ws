| | 사람(다한) | 젯슨 | 데스크톱 |

- 통로는 이 저장소 origin/master다. `logs/`는 git 제외이므로 판단에 필요한 수치와 그림은 LOG와 `docs/img/`에 넣는다.
- LOG 파일은 단계별로 나눈다: `docs/FW191_A_LOG.md`(업데이트·재확인), `FW191_B_LOG.md`(측정 체계), `FW191_C_LOG.md`(정지 후 진동), `FW191_D_LOG.md`(계층별 비교), `FW191_E_LOG.md`(거치대·AMR). 형식은 VIB_PLAN_1105 7절.

**4. "J5에도 추종층을 넣으면 안 되는가" — 젯슨 답이 맞다. 지금은 시험하지 않는다.**
