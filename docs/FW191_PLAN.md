센서: 팔 베이스 볼트 옆 = 마이크로스트레인(입력), 끝단 = 손목 카메라 IMU(출력, B-4 보정 적용), 관절 = 엔코더·토크 피드백.

- [ ] `[사람]` 팔을 거치대에 고정, 뻗은 자세(자세 B)에서 넘어가지 않는지 손으로 확인, 선을 거치대에 묶음, 바닥에 출발선·정지선
- [ ] `[젯슨]` E-2 잡음 바닥: 베이스로 옮긴 뒤 정지 60 s
- [ ] `[사람+젯슨]` E-3 정지 상태 타격: 선반을 툭 10회씩(앞뒤, 좌우, 위아래). 봉우리가 약 7 Hz와 맞는지. 세기를 바꿔 한 번 더(백래시 확인)
- [ ] `[사람+젯슨]` E-4 굴리기: 직선 3 m, 10회
- [ ] `[사람+젯슨]` E-5 턱 넘기: 낮은 턱·느린 속도부터 10회. 관절 편차가 중단 기준을 넘으면 그 조건에서 멈춘다
- [ ] `[사람+젯슨]` E-6 출발·정지: 10회
- [ ] `[젯슨]` 자세 A·B, 부하 0·0.2 kg으로 E-3–6 반복(자세 A 무부하가 먼저)
- [ ] `[젯슨]` 자체 검증: 2–3 Hz 아래 병진 전달률이 1 근처인지, E-3과 E-4 곡선이 겹치는지
- [ ] `[데스크톱]` 전달률 곡선(자세 A·B), 관절별 막대, 베이스 감속 크기 대 끝단 첫 봉우리 산점도(C의 그림과 같은 형식) → KROS 원고
- [ ] `[사람+젯슨]` AMR 도착 뒤: 손 끌기를 AMR 직선 가감속으로 바꿔 같은 절차. 배선·고정·두 젯슨 시각 동기는 그때 9절에 추가

거치대 값은 절댓값으로 AMR에 옮기지 않는다. 입력으로 나눈 값(전달률) 중심으로 쓴다.

## 8. 단계 D — 한 시나리오에서 계층별 비교 (G2 + C-1 뒤)

시나리오: J2, 자세 A에서 멈춤, 올림 → 3 s → 내림 → 3 s 왕복 6회. 속도·거리는 C-1 결과에서 데스크톱이 정한다. 한 시행을 운동 창과 정지 창으로 나눠 분석한다. 조건마다 5회, 시행 직전 기울기를 적고 처짐 무리가 다른 시행은 따로 묶는다.

- [ ] `[젯슨]` ①′ 조건 추가: MIT, 펌웨어 PD(A-3에서 정한 값) + 중력 보상만
- [ ] `[젯슨]` **D-1** 계층 비교: ① / ①′ / ② / ④-off / ④-on × 5 = 25회
- [ ] `[젯슨]` 60 s 이상 장시간 1회(④-on): 드리프트 지적에 대한 안정성 그림(QA_DRIFT 보강 항목)
- [ ] `[데스크톱]` 조건별 표(① 대비 비, 중앙값·범위), 계층별 막대 그림. 판정 문턱은 그대로(둘 다 ≤ 0.83 감소, 하나라도 ≥ 1.2 증가, 범위가 겹치면 경향)
- [ ] `[사람]` 영상: ① / ④-off / ④-on, 같은 구도·같은 시나리오. 자막에 조건 이름과 지표 값
- [ ] `[젯슨]` 외부 PID(적분항 추가), PD + 모델 피드포워드 옵션 → **D-2** B-PID / B-FF / B-LQR × 5 = 15회. B-LQR은 밀리면 빈칸
- [ ] `[젯슨]` **D-3** 조건 변화: ①·②·④-off·B-PID × (빠른 속도, 0.2 kg) × 5 = 40회. B-PID 게인은 기준 조건에서 한 번 맞추고 다시 맞추지 않는다
- [ ] `[젯슨]` 다관절 확장: J1·J3에 추종층을 넣고 3축 시나리오로 D-1 반복. J2 결과가 먼저
- [ ] `[데스크톱]` 국방로봇학회 자료(`research-notes/MRS_2026_DECK.md`)에 수치 반영
