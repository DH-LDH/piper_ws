### 10/23 — 조건 a′ 추가 확인, 논문 선택 기준에 홀바디 확장성 추가

- a′ 추가 동의. 저속 떨림이 진동억제의 실제 대상이므로 D0에서 **a′ 결과를 가장 무겁게** 본다.
- 논문 A/B 선택 기준은 두 가지다: ① D0 결과(구조 모드인가) ② **홀바디로 확장되는가**(박사님 우려). ②에 대한 현재 판단:

| | 베이스 움직임에 대해 | 한계 |
|---|---|---|
| A input shaping | 우리가 **명령한** 움직임(팔 궤적, 베이스 cmd_vel 가감속)이 만드는 진동만 다룬다. 베이스 명령도 shaping하면 확장은 된다 | 바닥 요철·접촉 같은 **모르는 외란**은 못 다룸. 모드가 자세·하중에 따라 바뀌면 다시 맞춰야 함 (LIST는 반복 학습이라 반복 작업 전제) |
| B 외란 관측기 | 원인을 가리지 않고 합쳐진 외란으로 추정 → 베이스 외란도 같은 틀 | **TDE가 이미 같은 일을 한다**(TDE도 일종의 외란 관측기). 대역폭은 100 Hz 루프·1–2주기 지연으로 똑같이 제한 → B를 넣는 의미가 TDE와 겹칠 위험 |

- 그래서 지금 기울어진 방향은 **"B 계열을 메인으로, TDE에 없는 정보를 더한다"** — 예: link6 IMU 가속도나 (홀바디 때) 베이스 가속도를 외란 추정의 추가 입력으로. A는 명령 쪽 보조(팔·베이스 궤적 shaping)로 남긴다. 최종 결정은 D0 결과(특히 a′)를 본 뒤.
- D0 LOG의 "판단 필요"에 위 ② 의견을 적는 것은 좋다. 추가로 **IMU 가속도와 q̇ 떨림의 위상·지연**(IMU가 q̇보다 먼저 떨림을 보는지)을 한 줄 적어 주면 B + IMU 방향 판단에 쓴다.

### 10/23 저녁 — D0(VIB_E1) 판단과 논문 확정, 구현 지시

**판단 필요 5개에 대한 답**

1. 구조 모드: **예, 동의.** 핵심은 "6–7 Hz 모드가 q̇에 안 보인다" — PiPER 엔코더는 모터 쪽이라 링크 쪽 탄성(감속기·링크)이 만드는 모드를 못 본다. TDC·SMC가 저속 떨림을 못 잡은 이유도 이것으로 설명된다.
2. 논문: **A(input shaping)는 메인에서 뺀다**(궤적이 이미 매끈하고 가진원이 움직이는 동안의 외란). B 중에서도 "모터 엔코더 + 손끝 관성센서로 링크 쪽 상태를 추정"하는 계열로 확정:
   - **메인: W. Chen, M. Tomizuka, "Direct Joint Space State Estimation in Robots With Multiple Elastic Joints," IEEE/ASME TMech 19(2) 697–706, 2014** (DOI 10.1109/TMECH.2013.2255308). 모터 엔코더 + EE 3축 가속도계 → kinematic Kalman filter로 링크 쪽 관절 상태 추정, 6축 산업용 로봇 실기. 우리 상황(모터 쪽 엔코더만, 저가 MEMS)과 정확히 같다. 정독·알고리즘 정리는 데스크톱이 하고 결과를 여기에 다시 쓴다.
   - 참고(이론): Keppler 외, "Elastic Structure Preserving (ESP) Control," IEEE T-RO 2018 — 링크 진동에 감쇠를 주입하는 제어 쪽. 2주 안에 재현은 무리, 보고 때 "다음 단계" 근거로만.
   - **우리 쪽 확장(=novelty 후보)**: 논문은 가속도계만 쓴다. D455에는 **자이로**도 있다 — 수직 모드는 link6의 피치 회전이므로 자이로가 링크 쪽 각속도를 적분 없이 직접 준다. 추정한 링크 쪽 속도를 **SMC 슬라이딩 변수와 감쇠 항에 넣는 것**이 "SMC + 진동억제 융합". 홀바디 때 베이스 외란도 같은 IMU로 본다.
3. IMU 빈틈: **반나절만 원인 조사**(USB 포트·허브 바꾸기, 수신 스레드 분리, 가속도 63 Hz / 자이로 200 Hz 등 낮은 설정 비교). 안 고쳐지면 그대로 간다 — Kalman filter는 빈틈 동안 예측만 하면 되므로 구조상 견딘다. 단 빈틈 비율·최대 길이를 매 시행 기록.
4. 진폭 의존: **지금은 안 본다.** LOG에 관찰로만 남김.
5. 토크 층: **MIT 하이브리드 위에서 한다.** 감쇠 주입은 토크 명령이 필요해 위치 모드 위에서는 할 수 없다. 순간 튐은 ① 튐 검출(이미 있는 1주기 속도 한계)로 구간 표시 ② 지표 계산에서 튐 ±0.5 s 제외 ③ 조건마다 최소 3회 반복. **펌웨어 V1.8.3 업그레이드는 11/05 전에는 하지 않는다**(영점 재설정 위험).

- [ ] **D2-0 IMU 실시간화**: `imu_rec`를 mit_probe 루프에서 최신값을 읽을 수 있는 형태로(별도 스레드, 장치 타임스탬프 유지). FK(J1–J6)로 카메라 자세 계산 → 중력 제거 → base 좌표의 EE 가속도·각속도. 오프라인으로 VIB_E1 a′ 데이터에 먼저 적용해 6–7 Hz가 base 수직축에 깔끔히 모이는지 확인

- [ ] **D2-2 감쇠 블록**: 4절 "τ 뒤 외란 보상 자리"에 `τ_vib = −D·(ω_l,est − q̇)` (링크–모터 속도 차 = 탄성 변형 속도에 감쇠). D는 0에서 아주 작게 키움. 하이브리드 J2·J3 정지 + 툭 → ζ·복귀 시간이 E1 조건 b(ζ 0.07–0.11, 670 ms)보다 좋아지는지
- [ ] **D2-3 SMC 융합**: 슬라이딩 변수에 링크 쪽 속도 반영 `s = ė_l + Ks·e` (e는 모터 쪽 위치 오차 유지, ė만 링크 쪽 추정). ASMC-2016 적응 법칙 그대로 + 경계층. τ_vib 단독과 비교
- [ ] **D3** 비교 실험 (5절): 비교군 = ① 위치 모드 ② 하이브리드 ③ 하이브리드 + τ_vib ④ 하이브리드 + ASMC(링크 속도 s). 상태 = 정지+툭(x·z), a′ 저속 J2·J3 사인파. 지표에 **IMU 5–10 Hz 대역 rms**(a′ 표와 같은 방식)를 1순위로

### 10/23 — D1 확인, D2-2 전에 정할 것 (TDE와 τ_vib의 관계)

D1 확인(bf70211): `step()`에서 `tau = tde + pd + sw + extra`이고 `commit(tau_sent)`가 extra까지 τ_prev로 넘긴다. 지금은 extra = 0이라 문제없지만 **D2-2에서 τ_vib를 넣을 때 의미가 달라진다.**

- TDC에서는 τ_prev로 이어지는 항은 모두 "원하는 가속도 × M̄"로 해석된다(그래서 pd도 M̄·u 꼴). 즉 extra를 지금 자리에 넣으면 τ_vib는 **감쇠 토크가 아니라 모터 쪽 가속도 명령 −(D/M̄)·Δv**로 작동한다.
- 반대로 extra를 τ_prev에서 빼고 넘기면, 그 효과가 다음 주기 q̈에 나타나 **TDE가 외란으로 보고 상쇄**하려 한다(상쇄 정도는 M̄ 크기에 비례).
- 어느 쪽이 링크 진동을 줄이는지는 2질량계(모터–스프링–링크)에서 따져 봐야 한다. 실기 전에:
  - [ ] `joint_ctrl`에 플래그 `dist_mode = "accel" | "torque"` 추가 — accel: 지금처럼 τ_prev에 포함, torque: `commit`에서 extra를 빼고 저장
  - [ ] **가짜 팔에 2질량 모델 추가**(`--fake-flex`): 모터 관성 + 스프링·감쇠 + 링크 관성, 링크 고유 주파수 7 Hz·ζ 0.05, IMU 대신 링크 속도를 그대로 내보냄. 지금 가짜 팔은 강체라 진동억제 효과를 볼 수 없다
  - [ ] 가짜 팔에서 두 모드 × D 몇 단계로 툭(링크에 충격) → 링크 쪽 ζ가 올라가는 모드와 D 범위를 VIB_E2_LOG에 기록, 실기는 그 범위의 1/3에서 시작
- D2-0(IMU 실시간화)은 이것과 무관하니 계획대로 진행.

- [초록] 2단계: (1) **최적화 기반 역미분기구학**으로 EE 가속도계 + 모터 엔코더에서 링크 쪽 관절 가속도(및 거친 상태)를 구함 — 즉 가속도를 관절 공간으로 옮길 때 자코비안을 쓰되 역행렬 대신 최적화(가속도 제약)로 푼다 (2) 관절마다 독립인 **2차 kinematic Kalman filter**로 위치·속도를 다듬음.

### 10/23 밤 — 젯슨 의견 반영: 논문 구성 확정안, 지연 대책으로 PPF

젯슨 의견(혼합안 찬성, NDOB ≈ "두 항에 같은 필터를 건 TDE", 지연이 최대 위험)에 모두 동의. 앞 항목의 "직전 4개 평균"은 **철회**(+20 ms 지연).

**논문 구성 (사용자 확인 후 확정)**

| 역할 | 논문 | 인용(OpenAlex) |
|---|---|---|
| **진동억제 메인** | Fanson·Caughey, "Positive position feedback control for large space structures," AIAA J. 1990 | **776** |
| 로봇팔 적용 예 | Shan·Liu·Sun, "Slewing and vibration control of a single-link flexible manipulator by PPF," Mechatronics 2004 | 149 |
| 링크 쪽 측정 방법 | Chen·Tomizuka, TMech 2014 (엔코더 + EE 관성센서) | 24 |
| 엔코더 기반 계열의 한계 근거 | W.-H. Chen 외 NDOB, TIE 2000 / Baek 외 ASMC, TIE 2016 | 1754 / 444(Scopus) |

- 근거 흐름: 엔코더 기반 외란 추정(NDOB·TDE)은 모터 쪽만 본다 → E1 조건 b, E2 "자이로가 엔코더의 3.6배"가 실측 → 자이로로 모드 좌표 측정 → **PPF로 감쇠 + ASMC로 추종 = 융합 아키텍처**
- PPF를 메인으로 고른 이유: ① 박사님이 말한 "진동 제어 고인용" 그 자체 ② **지연·위상에 강함** — 모드 주파수에 맞춘 2차 필터를 거쳐 양(+)으로 되먹임하므로 고주파(30–50 Hz 서보 떨림)는 굴려 떨어뜨리고, 필터 주파수 ω_f를 모드보다 조금 높게 잡아 루프 지연 위상을 흡수할 수 있다 ③ 모드 주파수가 조금 틀려도 불안정해지지 않는다(자세에 따라 6–7 Hz로 바뀌는 문제에 맞음)

**D2-2 수정: τ_vib = PPF**
- 필터: ξ̈ + 2ζ_f ω_f ξ̇ + ω_f² ξ = ω_f² δ, 토크 τ_vib = g·ω_f²·ξ (부호는 2질량 가짜 팔에서 확인 — 양되먹임 정의는 모드 좌표 부호에 따름)
- 입력 δ: 자이로 피치 변형 속도 δ̇(1.5 Hz 고역통과, 젯슨 제안대로 b 상태 대신)를 적분 — 적분 드리프트는 같은 고역통과로 막음. 또는 δ̇를 그대로 넣는 "속도형 PPF"와 비교
- 시작값: ω_f = 1.2·ω_n(FK 뻗음 거리로 6–7 Hz 스케줄), ζ_f 0.3–0.5, g는 0에서 키움
- 비교: −D·δ̇(단순 속도 감쇠) vs PPF — 지연을 일부러 늘려(+10·20 ms) 가짜 팔에서 둘 다 시험 → 지연에 대한 강건성이 PPF 쪽 주장 근거
- 젯슨 우려 ①(지연 보상 KF)은 PPF로 일부 대체 — KF 예측은 PPF로 부족할 때만

**젯슨 제안 그대로 채택**
- NDOB 비교: a′ J2·J3 한 조건 × 3회만, 일정 밀리면 가장 먼저 뺌
- ω_n 스케줄(FK 뻗음 거리), 제어 권한: 툭 데이터로 J2·J3·J5 변형 비중을 오프라인으로 먼저 추정 → τ_vib를 넣을 관절 결정
- 바이어스는 1.5 Hz 고역통과로, IMU 63/200 Hz 설정

#### Chen·Tomizuka, TMech 2014 — 확인된 내용

**① 상태·예측·측정**
- 모델 (1)–(2): 링크 쪽 동역학 + 모터 쪽 동역학, 관절마다 감속기 강성 K_J·감쇠 D_J·기어비 N (대각).
- **거친 링크 위치 (3)**: q̂° = (D̂_J s + K̂_J)⁻¹ [K̂_J N⁻¹ q_m + D̂_J N⁻¹ q̇_m − N(τ_m − M̂_m q̈_md − D̂_m q̇_m − F̂_mc sgn q̇_m)] — 모터 토크 균형으로 감속기 변형을 계산해 모터 위치에서 뺀다(전진 오일러, q̈_m 대신 목표 가속도). 오일러 미분으로 q̇̂°.
- **가속도 → 관절 공간 (6)·(14)·(15)**: p̈_e = J̄(q)q̈ + J̄̇(q,q̇)q̇ (J̄ = 자코비안 위 3행). 매 주기 min ½‖q̈ − Δq̈°‖² s.t. A_k q̈ = b_k, A_k = J̄(q̂°), b_k = p̈_e − J̄̇q̇. 닫힌 해 **q̈ = A†b + (I − A†A)Δq̈°**, A† = Aᵀ(AAᵀ)⁻¹ — 측정과 맞는 해 중 거친 추정에 가장 가까운 것. Δq̈° = (q̇̂° − q̇̂_{k−1})/Δt 에 이전 오차 누적분 포함.
- **관절별 독립 KKF (17)**: x = [q, q̇]ᵀ, x_{k+1} = [[1,Δt],[0,1]]x_k + [Δt²/2, Δt]ᵀ q̈̂_k + w_k, **측정 y_k = q̂°_k (모터 엔코더 원값이 아니라 (3)의 거친 링크 위치)**. 온라인은 전방 KF (19), 오프라인은 RTS 스무더 (20).

**② 중력·센서 자세 (16)**: p̈_e = R_a(q) f_a − g_s, g_s = [0 0 9.8]ᵀ. J̄, J̄̇, R_a에는 링크 쪽 참값 대신 **거친 추정 q̂°, q̇̂°** 를 쓴다(차이가 작아 충분하다고 주장).

**③ 공분산·표본 주기**: Q, R, x̂₁, P₁은 **EM(최대우도)** — 오프라인 (23), 온라인은 매 주기 (24) 후 지수 이동평균 (25), 창 N_Q = N_R = 500. 초깃값은 정지 구간의 분산. 공분산은 "그 궤적에 대해서만 최적"이라고 명시. **모든 센서·제어기 1 kHz**, 온라인은 100 Hz 인과 저역통과(위상 지연과 잡음의 절충), 오프라인은 30 Hz 영위상.

- **입력 x는 1 Hz 1차 고역통과만 거친 v**로 한다. η는 직류 이득이 1/Q라서, 고역통과가 없으면 자이로 바이어스·모델 오차 직류가 τ_vib 상수 오프셋으로 샌다. 4 Hz 고역통과는 8 Hz에서 +27° 위상을 더하므로 1 Hz(+7°)로 낮춘다. 16 Hz 저역은 뺀다(공진기가 대신함).
- **Q = 1.0.** Q 0.7/1.0/1.5를 비교하면 7–8.5 Hz 위상 기울기는 31°/37°/47°, 25 Hz 이득은 0.29/0.21/0.15다. 처짐에 따라 모드가 7.25–8.0 Hz로 움직이니 위상이 평평한 쪽(Q 1.0)을 고른다.

### 10/26 밤 6 — VIB_E4 10절(43964b1) 확인: 그대로 진행, 실제 제어 주기 하나 확인

공진기 예측기·RK4·감시 ②·게이트 상한·∠H/∠(−C) 분리를 모두 승인한다. 반암시 오일러가 8 Hz에서 13° 앞선다는 것을 잡아 RK4로 바꾼 것도 좋다. 시각 수정 전 회를 새 리포트로 다시 돌려 ∠(−C) −44 – −72°가 나온 것은 분리 리포트가 제대로 작동한다는 검증으로 본다. 내일 순서(a′ 건강 확인 → k = 0 처프 4–40 Hz → |L| < 0.3인 k까지만 → k = 0.2 AB)는 그대로 간다. 가짜 팔에서 리밋 사이클을 재현하지 못한 것은 실기 고주파 경로가 더 강하다는 뜻이니, 판정을 실기 |L|로 하는 것이 맞다.

**확인 하나 — 실제 제어 주기.** `--rate` 기본은 100 Hz(나이퀴스트 50 Hz)다. 그런데 9절은 "매 제어 주기 부호가 뒤집힘(약 25 Hz)"이라고 했다. 100 Hz 루프에서 매 주기 부호가 뒤집히면 50 Hz여야 한다.
- [ ] 리밋 사이클 회(172544 전후) CSV의 t 간격으로 **실제 루프 주기 분포**(중앙·95%·최대)를 확인해 달라. τ_vib(공진기 RK4 + IMU 처리)를 켠 뒤 루프가 밀려 실제로 약 50 Hz로 돌았다면 다음 셋이 걸린다.
  - ① 리밋 사이클은 **루프 나이퀴스트 발진**이고, 판정 기준은 "20–40 Hz |L|"이 아니라 **나이퀴스트 근처 |L|**다.
  - ② 4–40 Hz 처프의 25 Hz 이상은 앨리어싱이라 의미가 없다.
  - ③ TDE의 dt 가정도 틀어진다.
  - 그 경우 처프 상한을 실제 나이퀴스트의 0.8배로 내리고(`--fmax`도 같이), 루프 밀림의 원인(IMU 수신·RK4·로깅)을 먼저 줄인다.
- 루프가 100 Hz로 정상이었다면 "2주기마다 반전"이었다는 뜻이니 표기만 고치면 된다. 계획은 그대로다.

**4–40 Hz 처프 안전**: 20–40 Hz에는 기존 30–50 Hz 서보 떨림 대역이 걸쳐 있다. 첫 회는 ±0.12로 하되, 끝 구간(25 Hz 이상)에서 이탈·속도 감시가 평소보다 일찍 걸리면 그 회를 중단하고 상한을 25 Hz로 낮춰 다시 한다. 리밋 사이클이 25 Hz 근처였으니 그 아래 대역만으로도 판정의 핵심은 얻는다.
