## 3. D0 — 진단 실험: 떨림이 구조 진동인가, 루프가 만든 것인가

**질문.** E4·E5의 15–16 Hz 떨림은 고정 스위칭·적응 게인 발산 때 나왔다. 팔 구조의 고유 모드라면 진동억제 논문 A(input shaping, 궤적 쪽)가 맞고, 지연 + 스위칭이 만든 루프 떨림이면 A로는 안 잡히므로 B(외란 관측기, 토크 쪽)를 메인으로 한다.

- [ ] **조건 a — 펌웨어 위치 모드**(MIT 아님)로 자세 유지
  - 자세 2개: E3–E5 시작 자세 / 팔을 앞으로 뻗은 자세 (모드는 자세에 따라 바뀐다)
  - 가진 ①: EE를 손으로 가볍게 한 번 툭 (각 자세 3회, x·y·z 방향 하나씩)
  - 가진 ②: J1, J2, J3 각각 2° 스텝 명령 (`JointCtrl` 한 번)
  - 각 시행 10 s 이상 기록
- [ ] **조건 a′ — 펌웨어 위치 모드 저속 궤적** (10/22 발표의 "속도를 늦춰도 남는 떨림", 진동억제로 잡으려는 대상)
  - E5 느린 사인파와 같은 궤적을 `JointCtrl`로, J1 단독 1회 + EE가 움직이는 J2·J3 동시 1회
  - IMU와 q̇를 같이 기록해 떨림이 a의 고유 모드 주파수와 겹치는지 본다
- [ ] **조건 b — MIT 하이브리드 정지 유지** (`--tdc --hybrid`, J1, E5와 같은 파라미터), 같은 가진 ①
- [ ] **조건 c — 떨림이 났던 설정 재현** (`--tdc --sw-k 20 --sw-phi 1.0`, J1 사인파, E4 15:27 조건) 1회
- [ ] 기록: 6축 q, q̇, effort를 피드백 최대 주기(200 Hz 확인)로. **D455의 IMU(가속도, link6에 달려 있음)를 같이 기록**하면 EE 가속도를 공짜로 얻는다 — 가능하면 함께.

- [ ] 판정에 쓸 표 (7절 형식): 조건 a에서 저주파(수 Hz–20 Hz) 모드가 뚜렷하고 여러 주기 이어지는가 / a′ 저속 궤적의 떨림 주파수가 a의 모드와 같은가 / 15–16 Hz가 조건 c에만 있는가

### 10/23 — 조건 a′ 추가 확인, 논문 선택 기준에 홀바디 확장성 추가

- a′ 추가 동의. 저속 떨림이 진동억제의 실제 대상이므로 D0에서 **a′ 결과를 가장 무겁게** 본다.
- 논문 A/B 선택 기준은 두 가지다: ① D0 결과(구조 모드인가) ② **홀바디로 확장되는가**(박사님 우려). ②에 대한 현재 판단:

| | 베이스 움직임에 대해 | 한계 |
|---|---|---|
| A input shaping | 우리가 **명령한** 움직임(팔 궤적, 베이스 cmd_vel 가감속)이 만드는 진동만 다룬다. 베이스 명령도 shaping하면 확장은 된다 | 바닥 요철·접촉 같은 **모르는 외란**은 못 다룸. 모드가 자세·하중에 따라 바뀌면 다시 맞춰야 함 (LIST는 반복 학습이라 반복 작업 전제) |
| B 외란 관측기 | 원인을 가리지 않고 합쳐진 외란으로 추정 → 베이스 외란도 같은 틀 | **TDE가 이미 같은 일을 한다**(TDE도 일종의 외란 관측기). 대역폭은 100 Hz 루프·1–2주기 지연으로 똑같이 제한 → B를 넣는 의미가 TDE와 겹칠 위험 |

- 그래서 지금 기울어진 방향은 **"B 계열을 메인으로, TDE에 없는 정보를 더한다"** — 예: link6 IMU 가속도나 (홀바디 때) 베이스 가속도를 외란 추정의 추가 입력으로. A는 명령 쪽 보조(팔·베이스 궤적 shaping)로 남긴다. 최종 결정은 D0 결과(특히 a′)를 본 뒤.
- D0 LOG의 "판단 필요"에 위 ② 의견을 적는 것은 좋다. 추가로 **IMU 가속도와 q̇ 떨림의 위상·지연**(IMU가 q̇보다 먼저 떨림을 보는지)을 한 줄 적어 주면 B + IMU 방향 판단에 쓴다.
