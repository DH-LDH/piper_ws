# VIB_E2 — D2-0: IMU를 base 좌표로, 진동은 자이로 피치에 모이고 엔코더의 3.6배

2026-10-23 17시 · 실기 없음(VIB_E1 기록 재분석 + 손목캠만 연결한 IMU 수신 시험) · 도구 커밋: 이 LOG와 같은 커밋
명령: `source install/setup.bash; python3 tools/vib_d2_imu_check.py logs/vib/20261023_144309_slow_j23_poseA.csv logs/vib/20261023_145815_step_j3_poseB.csv`

**요약.** 손목 IMU를 FK와 장착 회전으로 base 좌표로 바꾸면, 저속 떨림(a′ J2·J3)은 **수직 평면의 피치 회전**으로 모인다 — 자이로 base y(피치)가 다른 축의 12배, 가속도는 z(수직) 0.65 > x(앞뒤) 0.33 m/s².
1 Hz 아래에서 자이로 피치와 엔코더(FK) link6 피치 속도가 상관 0.995, 크기도 같아(0.186 rad/s) 변환·단위가 맞다. 5–8 Hz에서는 **자이로가 엔코더의 3.6배**(결맞음 0.72) — 엔코더에도 일부 보이지만(E1의 "q̇에 안 보임"은 관절 하나씩 볼 때 얘기) 대부분은 엔코더 밖 변형.
IMU 빈틈은 **합산 표본 수에 비례** — 가속도 63 Hz·자이로 200 Hz로 낮추면 9–10% → 1–3%. 대신 수신이 몰려서 와 100 Hz 루프에서 읽는 최신값이 약 5%는 40 ms 넘게 묵음.

## 1. 장착 회전 (정지 중력으로 확인)

- D455 extrinsics: 가속도·자이로 → 컬러 회전 0.2° 이하, 이동 (−29, −7, −16) mm → IMU 축 = 컬러 광학 좌표(eih_cam).
- `R_base_imu = FK(q)의 link6 자세 · Ry(pitch) · Rz(roll)` (piper_eih_camera_node와 같은 정의). 비전 캘리브 값(27.5°, −90°)으로는 정지 중력이 수직에서 **3.1–3.5°** 어긋나고 두 자세(A·B)에서 같은 방향 → 장착 회전 오차.
- 정지 중력 맞춤: **pitch 30.75°, roll −88.25°**(자세 A·B, 최대 0.36°) → `src/common_pkg/imu_frame.py`. 두 자세가 모두 피치 축 쪽만 달라 roll은 불확실 — 다음 실기 때 J1·J4를 돌린 자세 몇 개로 다시 맞춤. 비전 캘리브 값은 비전 쪽이 쓰므로 그대로 둠.
- |정지 가속도| 9.67–9.72 m/s²(1% 작음) — 가속도계 배율·바이어스, 진동 분석에는 영향 작음.

| | 1 Hz 아래 상관 / rms (자이로·엔코더) | 5–8 Hz 결맞음 | 위상 | 크기비 | 변형 속도(자이로 − 엔코더) 5–10 Hz |
|---|---|---|---|---|---|

- 진동은 J2·J3·J5 축(모두 base y와 평행, J1≈0·J4≈0)의 피치 회전. 엔코더 피치 ≈ q̇2+q̇3+q̇5(상관 0.90).
- 자이로 위상 16–18° 늦음 = 7 Hz에서 약 7 ms — IMU 수신 지연 또는 링크 변형의 위상, 구분 못 함.

## 3. IMU 실시간 수신과 빈틈 (손목캠만 연결, 10 s씩)

`src/common_pkg/imu_stream.py`: SDK 콜백 스레드가 최신 가속도·자이로와 2 s 버퍼를 유지, `latest()`로 읽기만. 장치 타임스탬프 보관, 빈틈(간격 > 2.5×설정 주기) 횟수·길이 집계.

| 가속도 / 자이로 [Hz] | 가속도 빈틈 | 자이로 빈틈 | 최대 빈틈 | 100 Hz 루프에서 최신값 나이 중앙 / 95% |
|---|---|---|---|---|
| 250 / 400 (E1 설정) | 10.3% | 9.4% | 84 ms | 3.1 / 41 ms |
| 63 / 400 | 6.0% | 8.2% | 87 ms | 5.7 / 52 ms |
| 250 / 200 | 5.6% | 4.7% | 45 ms | 3.7 / 37 ms |
| **63 / 200** | 0.8–1.3% | 1.2–2.6% | 35–90 ms | 5.8–6.1 / 41–45 ms |

- 빈틈은 두 스트림 합산 표본 수에 비례 → USB HID 수신량 한계로 추정. **D2부터 63 / 200 Hz**(주 측정 자이로 200 Hz ≫ 7 Hz). USB 포트 교체는 필요하면 나중에.
- 그래도 수신이 몰려 와서 최신값이 5%쯤은 40 ms 넘게 묵음 — 7 Hz에서 위상 약 100°. **IMU 최신값을 그대로 감쇠에 넣으면 위험**, 엔코더로 예측을 이어 가는 추정기(D2-1)가 메워야 함. 장치 타임스탬프로 표본 시각을 복원해 쓰는 것이 전제.

## 검증 (8절 지시 확인)

- "자이로 피치를 주 측정으로": **확인** — 진동이 base y 각속도에 모이고 엔코더 대비 3.6배.
- "6–7 Hz가 base 수직축에 깔끔히 모이는지": **확인** — 가속도 z > x ≫ y, z 피크 5.8–6.3 Hz(자세 A의 a′는 움직이는 동안이라 정지 툭의 7 Hz보다 낮음).
- "IMU 빈틈 반나절 조사": **설정 비교로 해결**(63/200 Hz, 1–3%). 다만 최신값 나이 문제가 새로 보임 → 판단 필요 2.
- D2-2 `τ_vib = −D·(ω_l,est − q̇)`: 부호는 아직 미확인. 스프링에 병렬 가상 댐퍼를 붙이는 관점에서는 모터 쪽 토크가 `+D·(ω_l − ω_m)` 꼴이라 지시와 반대 — **2질량 가짜 팔에서 두 부호 × accel/torque 모드로 확인할 예정**.

## 판단 필요 (데스크톱)

1. 장착 회전은 중력 맞춤 값(30.75°, −88.25°)을 IMU 변환에만 쓰고 비전 캘리브는 그대로 둠 — 비전 쪽도 다시 캘리브할지.
2. IMU 지연(중앙 6 ms, 95% 40 ms 이상)을 D2-1 설계에 반영: 장치 타임스탬프로 표본 시각을 복원하고, KF가 늦게 온 측정을 과거 시점에 넣는 방식(지연 측정 처리)이 필요할 수 있음 — Chen·Tomizuka 정리에서 표본 주기·지연을 어떻게 다뤘는지 확인 부탁.
3. "q̇에 안 보임" 정정: 엔코더 link6 피치에는 진동의 약 1/3.6이 보임(모터 쪽도 같이 흔들림). 추정기 상태에 이 결합이 들어가야 함.

- **실기 네 특징에 맞는 파라미터를 못 찾음**: ① 하이브리드 정지 툭 6.7–6.9 Hz·ζ 0.07–0.11·안정(E1 b) ② 순수 TDC J2 M̄ 0.01 안정·0.02 발진(E4) ③ 하이브리드 툭에서 엔코더/자이로 피치 0.17(위치 모드 툭 0.05–0.42, a′ 0.28).
  - 마찰 없음: 7 Hz 모드가 생기면 하이브리드 TDE가 항상 음의 감쇠(지연된 스프링 토크 되먹임)로 리밋 사이클 — 실기와 반대.
  - 마찰 있음: 기준은 안정하지만 작은 진동에서 모터가 붙어(모터/링크 0.00) 모터 토크가 모드에 안 닿음 — 실기(0.17)와 다름.
- 함의: **모터 토크로 넣는 감쇠가 정지 중 작은 진동에 닿는지는 마찰·백래시에 달림.** 모델로 부호·안정 한계를 정하면 실기와 어긋날 위험 → 판단 필요 4.
